**Introduction**

    HTTP (Hypertext Transfer Protocol) is a core protocol of the Internet that enables data transfer between a client and a server. It is primarily used to fetch resources such as HTML documents and forms the foundation of data exchange on the Web.

    HTTP follows a client-server model, where communication is initiated by the client—typically a web browser. Clients and servers interact by exchanging individual messages:
         The client sends a request.
         The server responds with a response.

    Due to its extensibility, HTTP is not limited to just hypertext documents. It can also be used to retrieve images, videos, and even partial content to update web pages dynamically

**Components of HTTP**

1. **Client** : 
   This role is primarily performed by the Web browser, but it may also be performed by programs used by engineers and Web developers to debug their applications.The browser is always the entity initiating the request. 

2. **The Web Server** : 
   On the opposite side of the communication channel is the server, which serves the document as requested   by the client. A server appears as only a single machine virtually; but it may actually be a collection of servers sharing the load (load balancing), or other software (such as caches, a database server, or e-commerce servers), totally or partially generating the document on demand.

3. **Proxies** :
 A proxy is like a middleman between browser and a website.When we open a website, the request doesn’t always go directly to the server. It often goes through a proxy server first, which can check, change, or save the request before sending it to the website.
 Proxies may perform numerous functions: 
 
 * Caching : Saves a copy of websites so they load faster next time.
 * Filtering :  Blocks bad or unwanted websites (like for kids or office use).
 * Load Balancing: Shares traffic between servers so none of them get overloaded.
 * Authentication: Allows only certain people to access a website or resource.
 * Logging :  Keeps a record of websites visited, often for tracking or reports.
